## 🎨 2. CHI TIẾT DESIGN TOKENS & CẤU HÌNH ANT DESIGN V5

### 2.1 Bảng Màu Cốt Lõi (Dark-First Theme)
- **Background chính (`colorBgBase`):** `#0A0A0C` (Nền đen sâu sang trọng, gần như tuyệt đối).
- **Background Card & Bento (`colorBgContainer`):** `#121216` (Nổi bật nhẹ trên nền chính).
- **Điểm nhấn thương hiệu (`colorPrimary`):** `#38BDF8` (Electric Blue / Sky Blue rực rỡ nhưng dịu mắt).
- **Văn bản chính (`colorTextBase`):** `#F4F4F6` (Trắng dịu, không gây chói lóa).
- **Văn bản phụ (`colorTextSecondary`):** `#A1A1AA` (Xám tro hài hòa).
- **Viền Card (`colorBorderSecondary`):** `#23232E` (Mỏng 1px tinh tế).

### 2.2 Ant Design Theme Config Code Snippet
```typescript
import { ThemeConfig, theme } from 'antd';

export const antDarkTheme: ThemeConfig = {
  algorithm: theme.darkAlgorithm,
  token: {
    colorPrimary: '#38BDF8',
    colorBgBase: '#0A0A0C',
    colorBgContainer: '#121216',
    colorBgElevated: '#1A1A22',
    colorBorderSecondary: '#23232E',
    colorTextBase: '#F4F4F6',
    colorTextSecondary: '#A1A1AA',
    borderRadius: 12,
    fontFamily: 'var(--font-sans)',
  },
  components: {
    Button: { controlHeight: 42, borderRadius: 10 },
    Card: { colorBgContainer: '#121216', borderRadiusLG: 16 },
    Timeline: { itemPaddingBottom: 28 },
    Tag: { borderRadiusSM: 6 },
    Input: { colorBgContainer: '#16161D', colorBorder: '#2B2B38' }
  }
};
```
